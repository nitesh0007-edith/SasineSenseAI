# Data

Do not commit sensitive, copyrighted, or restricted source documents.

Recommended local layout:

```text
data/
  raw/
  annotations/
  uploads/
  rendered/
  derived/
  gazetteer/
```

For public research material, record:
- source URL
- archive/source name
- retrieval date
- document ID
- reuse/license terms
- whether redistribution is permitted
